I develop wireless sensing capabilities that allow robots to estimate signal directionality in real time using onboard sensors and computing platforms. This work includes algorithms that leverage arbitrary three-dimensional robot motion, analysis of position-estimation errors, and an open-source C++ implementation.

The systems have been deployed across ground and aerial platforms using WiFi channel state information, very-high-frequency beacons, and software-defined radios.
